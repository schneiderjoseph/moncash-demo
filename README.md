# MonCash Demos

![MonCash](./assets/moncash-logo.png)

> Exemples d'intégration MonCash par framework — by [Zygrec](https://zygrec.com)

Ce dépôt regroupe des démos pour tester l'API MonCash (Digicel Haïti) avec différents stacks.

| Framework | Dossier | Statut |
|-----------|---------|--------|
| **Node.js** | [`node/`](./node/) | Disponible — toutes les APIs SDK 1.1.0 |
| PHP | `php/` | Bientôt |
| Python | `python/` | Bientôt |

## SDK

Toutes les démos utilisent le package npm [`@zygrec/moncash`](https://www.npmjs.com/package/@zygrec/moncash).

- [Documentation SDK](https://github.com/schneiderjoseph/moncash)
- [Dashboard sandbox MonCash](https://sandbox.moncashbutton.digicelgroup.com/Moncash-business/Login)

## Démarrage rapide (Node.js)

```bash
cd node
cp .env.example .env
npm install
npm start
```

Voir [`node/README.md`](./node/README.md) pour le détail.
